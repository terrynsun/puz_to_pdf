This is a large-ish fork/refactor of a node hack of njyoon's fork of
Crossword Nexus' puz to pdf converter.

Changes were made mostly to generate pretty graphics for APIHMinis, including
changing PDF size, adding background image, more shading options, etc.

The original can be found at [https://njyoon.github.io/pdf](https://njyoon.github.io/pdf). I've probably broken or possibly removed some options in the process of getting this to work.

Usage:

```
./main.js my.puz
```
